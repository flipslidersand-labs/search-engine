# ADR-001: キーワード検索とベクトル検索の統合に RRF（k=60）を使う

**ステータス:** Draft  
**決定日:** 未確認（遡及記録: 2026-10-28）  
**review_by:** 2026-11-17

> 雛形: [ADR-000-public-template](https://github.com/flipslidersand-labs/repo-compass/blob/master/docs/adr/ADR-000-public-template.md)。遡及して書いた記録で、当時の比較経緯は推定していない。

---

## 課題

BM25（キーワード）は固有名詞やコードの完全一致に強く、ベクトル検索は言い換えに強い。
両者のスコアは尺度が違うため、そのまま足し合わせると偏る。

## 決定

2 つの検索結果を、スコアではなく順位だけを使う RRF（Reciprocal Rank Fusion）で統合する。定数 `k` の既定値は 60（`searchengine/hybrid.py` の `rrf_merge`）。

## 理由

- 順位だけを使うので、尺度の違うスコアを正規化する必要がない。
- **却下した代替案:** スコアの重み付き和。比較した記録はない（当時の検討は未確認）。
- `k=60` の値の根拠は、この記録からは確認できない。

## 影響

- 統合の精度を、どの質問セットで測ったかの記録は、このリポにはない（→ 検索の評価は別途必要）。
- `k` や重みを変えたときの効果は、未測定。

## 再検討条件

質問セットで検索の精度を測れるようになったとき、または `k` を変えて比較するとき。
